# INVESTLAB — QR 멀티플레이 투자 시뮬레이터

교육용 가상 투자 게임입니다. 실제 돈을 쓰지 않습니다.

## 포함 기능
- 방 생성 및 6자리 방 코드 참가
- 초대 링크와 QR 코드 생성
- Socket.IO 실시간 참가자/자산 상태 공유
- 가상 자금 10,000원, 5라운드
- 6개 가상 자산 분야, 분야별 랜덤 사건 수익률
- 투자 금액 선택 및 라운드별 수익/손실 계산
- 저렴한 힌트(50원): 크게 움직일 분야만 안내
- 정밀 힌트(200원): 다음 사건과 분야별 가상 변동률 공개
- 방장 라운드 정산 및 다음 라운드 진행
- 종료 후 자산 순위 표시

## 내 컴퓨터에서 실행 (Windows)
1. Node.js 18 이상 설치
2. 압축을 푼 폴더에서 터미널/PowerShell 열기
3. 아래 명령 실행:

```bash
npm install
npm start
```

4. 같은 컴퓨터에서 `http://localhost:3000` 접속

QR 초대 링크가 다른 휴대폰에서도 열리게 하려면 인터넷에 배포해야 합니다. `localhost`는 본인 컴퓨터에서만 열립니다.

## GitHub에 올리고 인터넷에 배포
GitHub Pages는 정적 웹페이지를 호스팅하지만 이 프로젝트의 실시간 멀티플레이 서버(Socket.IO)는 실행하지 못합니다. 이 프로젝트 전체를 Node.js 웹 서비스로 배포하세요.

일반적인 Node.js 호스팅 서비스에서:
- 저장소에 `package.json`, `server.js`, `public/index.html` 업로드
- Build command: `npm install`
- Start command: `npm start`
- 환경 변수 `PORT`는 호스팅 플랫폼이 자동 제공하도록 둡니다.
- 배포 완료 후 HTTPS 주소를 열어 방을 만들고 QR 코드를 공유합니다.

## 알아둘 점
- 방 상태는 메모리에 저장됩니다. 서버가 재시작되면 진행 중인 방은 사라집니다.
- 방은 최대 12명까지 참가할 수 있습니다.
- 현재는 데모 버전으로, 계정/비밀번호나 영구 기록은 없습니다.
- QR 생성은 브라우저에서 QRCode.js CDN을 불러옵니다. 인터넷 연결이 필요합니다.
- 투자 수익률과 사건은 게임용으로 만든 가상 값이며 실제 시장을 예측하지 않습니다.
